# Projeto Financeiro

Sistema de controle financeiro com cadastro de pessoas e gerenciamento de transações.

---

## Tecnologias utilizadas

### Back-end
- C# / .NET
- ASP.NET Web API
- Scalar (visualização e teste dos endpoints)
- SQLite

### Front-end
- React + TypeScript
- Vite

---

## Como rodar o projeto

### Back-end

1. Abra o projeto no **Visual Studio**
2. Defina o projeto como *Startup Project*
3. Execute a aplicação (HTTP)

A API estará disponível em `http://localhost:5012/scalar`

---

### Front-end

1. Navegue até a pasta do front-end:

```bash
cd controle-financeiro-front
```

2. Instale as dependências:

```bash
npm install
```

3. Execute o projeto:

```bash
npm run dev
```

Acesse no navegador: `http://localhost:5173`
