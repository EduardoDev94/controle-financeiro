# 📌 Projeto Financeiro

Sistema de controle financeiro com cadastro de pessoas e gerenciamento de transações.

---

## 🚀 Tecnologias utilizadas

### 🔧 Back-end
- C#
- .NET
- ASP.NET Web API
- Scalar para vizualização e teste dos endpoints

### 🎨 Front-end
- React
- TypeScript
- Vite

### 💾 Persistência de dados
- SQLite

---

## ⚙️ Como rodar o projeto

### 🔙 Back-end

1. Abra o projeto no **Visual Studio**
2. Defina o projeto como *Startup Project*
3. Execute a aplicação (HTTP)

A API estará disponível em:

http://localhost:5012/

---

### 🔜 Front-end

1. Abra o terminal na pasta do projeto front-end:

```bash
cd nome-da-pasta-front

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Acesse no navegador:

http://localhost:5173
